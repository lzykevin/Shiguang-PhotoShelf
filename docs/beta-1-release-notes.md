# 拾光 1.0.0-beta.1

首个开源测试版，面向愿意反馈问题的早期使用者。需要 macOS 14+，支持 Apple Silicon 与 Intel。

## 已包含

- 本地文件夹索引、照片浏览、多种布局、日期分组与沉浸式看图。
- 评分、收藏、相册、标签、备注、批量整理、撤销重做及智能相册。
- 日期／标签筛选、双向排序、照片对比及自动播放。
- 原片副本导出、整理数据备份／恢复。
- 移除来源保留评分、标签、备注、收藏和相册关联；重新添加同一文件夹恢复，覆盖移除、重启、重新添加和备份回归测试。
- Sparkle 更新菜单及自动检查设置。首次公开测试期间，更新源保持为空，尚不推送安装包。

## 安装与更新限制

附件是 ad-hoc 签名、未公证的开发测试包，不是 Developer ID 分发包；macOS 可能拦截从互联网下载的应用。没有修改或关闭系统安全设置的要求。普通用户可等待正式签名、公证版本，也可按 README 自行构建。

自动检查默认关闭，可在“拾光 → 设置 → 软件更新”开启。更新检查不上传照片或整理数据。完整的旧版到新版自动安装链路尚未验收，因此本次不宣称自动升级已正式可用。

## 验证与已知边界

- 本地 70 项自动化测试通过，Release 构建及 Sparkle 框架嵌入检查通过。
- 实际启动、菜单入口和更新设置界面已检查；本地签名框架加载问题已修复。
- Sparkle 更新包签名与签名验证通过。
- 尚未完成另一台 Mac 的互联网下载／Gatekeeper 首次安装和完整升级验收。
- 使用前建议分别备份原片和整理数据。整理数据备份不包含照片原文件。

问题反馈请提供版本、macOS 版本及复现步骤，并移除截图和日志里的私人信息。
