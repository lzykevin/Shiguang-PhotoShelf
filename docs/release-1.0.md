# 拾光 1.0 正式版

Swift 原生 macOS 本地照片管理应用，让个人照片值得回看、容易整理、随时找得到。

## 主要功能

- 本地文件夹关联、增量索引、多种布局、日期分组与沉浸式看图。
- 星级评分、爱心收藏、相册、标签、备注，支持批量整理和撤销重做。
- 日期与标签筛选、智能相册、双向排序、照片对比及自动播放。
- 导出照片副本、系统分享、整理数据备份与恢复。
- 移除来源保留整理信息，重新添加同一文件夹即可恢复。
- 内置 11 张风景照片、旅行精选相册及示例标签，首次使用一键体验。
- 应用内检查更新与自动检查设置。

## 安装

需要 macOS 14 或更新版本，支持 Apple Silicon 与 Intel。

下载 `PhotoShelf-1.0.0.zip`，解压后将应用拖入“应用程序”。
