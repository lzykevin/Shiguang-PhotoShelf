# 拾光 · 原生交互 Demo

本阶段确认照片浏览界面的视觉和交互，不接入真实图库。SwiftUI 绘制界面，AppKit 提供真实窗口、菜单、文本编辑及键盘事件。原有 `Sources/` 完整应用保持独立。

## 打开与构建

应用：`build/PhotoShelf Demo.app`。

项目根目录执行 `./scripts/build-demo.sh`。需要 Xcode Command Line Tools；Apple Silicon、macOS 14+。独立应用标识 `com.photoshelf.interaction-demo`，不打开旧版本数据库。构建为本地 ad-hoc 签名，不代表已完成分发认证。

## 当前行为

- 单击选择，双击或空格进入全屏，Esc 返回原窗口。
- 全屏默认只显示照片；移动鼠标显示顶部信息和底部浮动栏，离开控件区静置 2.5 秒隐藏。停在控件区保持显示。方向键切图和数字键评分会显示反馈。
- 0–5 评分；再次点击当前星级清除评分。首张/末张导航按钮有禁用状态。
- 全部、未评分、1–5 星一步筛选。普通点击替换，Command 点击追加或取消；多项为并集，取消最后一项恢复全部。数量区域和每个筛选项固定宽度。
- 点击搜索框任意空白处或 Command-F 聚焦。Esc 先清空关键词，再按退出编辑。文本基线和清除按钮预留空间固定。
- 相册、标签、五星精选、待评分、最近浏览、搜索均操作示例数据。无结果时清除筛选保留当前相册。
- 主题切换、收起信息区、缩略图大小、倒序排列、名称显隐、备注编辑保留。
- 窗口菜单 Command-1 标准尺寸、Command-2 紧凑尺寸，全屏内禁用尺寸切换。
- Command-R 重新开始演示，恢复示例数据、排序、大小、名称、信息区和最近浏览，保留主题。重启不保存修改。

历史 Demo 需要在本机 `output/示例照片/2026/秋日旅行/` 放入 11 张有权使用的 JPG；照片不随开源仓库分发。标题、相册、标签和初始评分为演示编排，不是真实照片元数据。不读取用户照片、不扫描目录、不联网。

## 界面约定

196 点侧栏、264 点信息区，顶部 72 点（含标题栏空间）。照片保留原比例，瀑布流列间距 12 点，内边距 16 点；单元格遵循实际可用宽度，滚动条不挤占列间距。筛选器采用成组选中态；信息区固定预览高度、统一标题与字段层级。蓝色用于导航和选择，金色用于评分，浅色模式使用更深的蓝色提高对比。

搜索聚焦、悬停和全屏控件采用短淡入淡出，避免缩放文字或动画重排。动画遵循系统减弱动态效果设置。选中、评分和禁用状态有辅助功能描述；尚未完成完整 VoiceOver 验收。

## 2026-11-03 两轮运行验收

第一轮检查标准深色、紧凑深色、浅色搜索空态和键盘搜索。发现并在第二轮修正：滚动条出现后卡片按外层宽度计算挤窄间距、浅色选中对比偏弱、全屏控件悬停保持依赖 SwiftUI tracking 不够可靠。

第二轮实际验证：

- 标准与 1060 × 680 紧凑窗口无工具栏重叠，照片不拉伸，列间距恢复一致。
- 深浅色画廊、详情区和选中态截图检查。
- 搜索聚焦前后放大对比基线一致；Command-F 聚焦；搜索无结果，Esc 清空和退出编辑。
- 四星 2 张，Command 追加五星 4 张；森林相册内五星无结果，清除条件仍保留森林相册 2 张。
- 双击全屏、方向键切图、数字评分、Esc 恢复原窗口；首张上一步禁用、末张下一步禁用。
- 用实际鼠标坐标点击并停在浮动栏超过 3 秒仍保持显示；移至照片区后超过 3 秒自动隐藏。辅助功能点击不一定移动真实指针，不能单独作为悬停验证。
- 全屏内 Command-2 没有缩小无边框窗口。
- 重新开始演示恢复 11 张及初始评分。
- 最新构建成功，`codesign --verify --deep --strict` 通过。
